# Beesbury – AI Assistant Web App  

**Beesbury** is a sleek and interactive AI-powered assistant built for the web. It allows users to chat, explore intelligent responses, and experience a smooth, modern UI powered by HTML, CSS, and JavaScript.  

🔗 Live App: [beesbury.vercel.app](https://beesbury.vercel.app/)  
📦 Repo: [GitHub](https://github.com/G24-gem/Beesbury)  

---

## 🚀 Features  

- **AI-Powered Chat** – Get intelligent responses in real-time  
- **Modern UI** – Clean, responsive, and minimal design  
- **Fast & Lightweight** – Built with vanilla JS, optimized for performance  
- **Deployment Ready** – Hosted on Vercel for smooth access  

---

## 🛠️ Tech Stack  

- **Frontend**: HTML5, CSS3, JavaScript (ES6)  
- **Deployment**: Vercel
